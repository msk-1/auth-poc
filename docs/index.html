OAuth 2.0 / OpenID Connect — Study Notes

oauth &
openid connect

SPA から Web API を安全に呼ぶために、認証と認可の仕組みを仕様の言葉で説明できるようになるための学習ノート。

「ログインには OAuth を使う」「トークンは localStorage に置く」——よく聞くが、どこまで正しいかがあいまいな人に向けて書いている。OAuth 2.0 は認可、OpenID Connect は認証という区別から始め、SPA × Web API の構成を選び、実装で確認すべき点までを順に扱う。

  1. GOAL 01認証と認可の違い、アクセストークンと ID トークンの役割の違いを説明できる
  2. GOAL 02認可コードフロー + PKCE の各パラメータが、どの攻撃を防いでいるかを説明できる
  3. GOAL 03SPA × Web API で BFF とブラウザ内クライアントのどちらを選ぶかを、脅威から判断できる

chapters

policy

  • 説明は IETF の RFC と OpenID Foundation の仕様に基づく。章の末尾に根拠とした仕様を載せる
  • コードや HTTP のやり取りは説明のための作例である。実際の値は利用する認可サーバー（Keycloak、Auth0、Entra ID、Cognito など）の資料で確認する
  • ドラフト段階の仕様（OAuth 2.1、OAuth 2.0 for Browser-Based Applications）は内容が変わり得る。最新の版を確認する
